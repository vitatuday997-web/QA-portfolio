# QA Shop — результаты тестирования

## Позитивный E2E-сценарий

### Сценарий

1. Создана новая sandbox для изолированной работы с тестовыми данными. Получены ключ sandbox и данные тестового пользователя.

2. Выполнена авторизация пользователя через API с использованием email, password и ключ sandbox. В ответ получен токен авторизации для дальнейших запросов.

3. Получен список товаров через API. Выбран товар из каталога.

4. Получен список вариантов выбранного товара через ID товара. Выбран вариант товара с доступным остатком.

5. Создана новая корзина.

6. Выбранный вариант товара добавлен в корзину в количестве 1 штуки.

7. Получены данные корзины через API и проверено, что товар действительно находится в корзине, количество и стоимость совпадают с ожидаемыми.

8. На основе корзины создан заказ.

9. Получены детали созданного заказа через API. Проверены статус заказа, состав, количество товара, цена и итоговая сумма.

10. Через PostgreSQL проверено наличие созданного заказа и связанных с ним позиций в базе данных.


## Что проверено через API

- Успешная авторизация пользователя и получение токена авторизации.
- Получение списка товаров и вариантов товара.
- Создание корзины для авторизованного пользователя.
- Добавление выбранного варианта товара в корзину.
- Наличие нужного товара в корзине.
- Создание заказа на основе существующей корзины.
- Получение созданного заказа по его ID.
- Соответствие данных заказа данным корзины:
  - выбранный `variant_id`;
  - количество товара;
  - цена товара;
  - итоговая сумма;
  - статус заказа `placed`.


## Что проверено в PostgreSQL

- В таблице `orders` существует созданный через API заказ.
- `id`, статус и итоговая сумма заказа совпадают с данными, полученными через API.
- В таблице `order_items` существует позиция, связанная с созданным заказом.
- `variant_id`, количество товара, цена и итоговая стоимость позиции совпадают с данными API.


## Результат

Позитивный E2E-сценарий оформления заказа выполнен успешно.

Проверена цепочка:

`авторизация → выбор товара → выбор варианта → создание корзины → добавление товара → создание заказа → получение заказа → проверка данных в PostgreSQL`

Данные, полученные через REST API, соответствуют данным, сохранённым в PostgreSQL.
