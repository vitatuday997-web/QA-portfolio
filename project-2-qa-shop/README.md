# QA Shop - API & БД тестирование

Учебный QA-проект по тестированию backend интернет-магазина через REST API и PostgreSQL.

Цель проекта - пройти основной пользовательский сценарий оформления заказа через API и проверить, что изменения корректно сохраняются в базе данных. 

## Объект тестирования

REST API интернет магазина QA Shop и связанные данные с PostgreSQL

Проверялся основной E2E-сценарий:

`авторизация → выбор товара → выбор варианта → создание корзины → добавление товара → создание заказа → получение заказа → проверка данных в PostgreSQL`

## Инструменты

- Postman
- PostgreSQL
- DBeaver
- Docker
- SQL
- JSON
- OpenAPI

## Что проверено

Через REST API:

- авторизация пользователя
- получение списка товаров
- получение вариантов товара
- создание корзины
- добавление товара в корзину
- получение содержимого корзины
- создание заказа
- получение деталей созданного заказа
- соответствие товара, количества, цены и итоговой суммы между корзиной и заказом

Через PostgreSQL:

- наличие созданного заказа в таблице `orders`
- соответствие `id`, статуса и суммы данным API
- наличие позиции заказа в таблице `order_items`
- соответствие `variant_id`, количества и стоимости данным API

## Структура проекта

- `postman/qa-shop.postman_collection.json` - Postman Collection с использованными API-запросами
- `sql/checks.sql` - SQL-запросы для проверки данных после выполнения API-сценария
- `test-notes.md` -описание выполненного E2E-сценария и результатов проверки
- `docker-compose.yml` - конфигурация локального запуска QA Shop и PostgreSQL
- `openapi.ru.yaml` - локальная версия OpenAPI-документации


## Результат

Позитивный E2E-сценарий оформления заказа выполнен успешно.
Данные, полученные через REST API, соответствовали данным, сохранённым в PostgreSQL.
Проект выполнен в учебных целях и не является коммерческим опытом.
