# Требования Pocket Notes

## Объект тестирования

Интерактивная WebGL-модель устройства Pocket Notes

## Источник требований

Требования сформированы на основе описания управления Pocket Notes и логики интерактивной модели

## Устройство

- Устройство должно включаться и выключаться
- Управление устройством осуществляется колесом мыши и средней кнопкой мыши
- Колесо мыши повторяет вращение колеса устройства
- Средняя кнопка мыши повторяет нажатие на колесико устройства
- Кнопка включения должна срабатывать только при прямом взаимодействии с ней

## Работа со списком заметок

- Пользователь может прокручивать список заметок колесом мыши
- Выбранная заметка выделяется черной рамкой
- Пользователь может открыть выбранную заметку нажатием средней кнопки мыши
- Пользователь может вызвать удаление выбранной заметки двойным нажатием средней кнопки мыши
- Пользователь может подтвердить удаление заметки
- Пользователь может отменить удаление заметки

## Создание и редактирование заметок

- Пользователь может создать новую заметку
- Заметка содержит заголовок и текст
- Пользователь может редактировать существующую заметку
- Колесо мыши внутри заметки перемещает курсор между строками
- Shift + колесо мыши перемещает курсор между символами

## Режимы ввода

- При удержании Shift вводятся заглавные буквы
- Одиночное нажатие Shift переключает режим специальных символов
- Повторное нажатие Shift возвращает обычный режим ввода
- Вводимый символ должен соответствовать символу на клавише устройства

## Избранное

- Пользователь может добавить заметку в избранное
- Пользователь может убрать заметку из избранного
- Содержимое избранной заметки отображается на главном экране
- Содержимое избранной заметки не должно выходить за границы области отображения
- После снятия статуса избранного с другой заметки ранее выбранная избранная заметка должна сохранять статус избранной
