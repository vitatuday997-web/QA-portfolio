# Чек-лист Pocket Notes

## Запуск
    
- Сайт открывается - PASS
- Интерактивное окно загружается без ошибок - PASS
- Устройство включается - PASS
- Устройство выключается - PASS

## Интерактивная модель
- Открывается на полный экран - PASS
- Можно создать заметку - PASS
- Ввод заголовка работает - PASS
- Enter в поле заголовка, переводит курсор ввода на содержимое заметки, для написания текста - PASS
- Слова переносятся на новую строку, при достижении поля ввода - PASS
- Прокрутка между строк - PASS
- Прокрутка между символами с зажатым Shift - PASS
- Вернуться в список заметок - PASS
- Прокрутка между заметок - PASS
- Статус избранного переключается - PASS
- Содержание избранной заметки отображается на главном экране - PASS
- Длинный текст избранной заметки не выходит за границы области отображения - FAIL
- Снятие избранного у другой заметки не сбрасывает ранее выбранную избранную заметку - FAIL
- Существует подтверждение удаления заметки - PASS
- Заметка удаляется - PASS
- Можно отменить удаление при подтверждении удаления заметки - PASS
- При удалении избранной заметки, её содержание удаляется с главного экрана - PASS
- С зажатым шифтом, вводятся большие буквы - PASS
- Режим письма переключается - PASS
- В режиме специальных символов каждой клавише соответствует корректный символ — FAIL

## Интерактивное управление
- Основные элементы управления мышью работают - PASS
- Кнопка включения реагирует только при прямом наведении на неё - FAIL
