# Чек-лист Pocket Notes

## Запуск
    
- Сайт открывается - PASS
- Интерактивное окно загружается без ошибок - PASS
- Устройство включается - PASS
- Устройство выключается - PASS

## Интерактивная модель

- Можно создать заметку - PASS
- Ввод текста работает - PASS
- Прокрутка между строк - PASS
- Прокрутка между символами - PASS
- Вернуться в список заметок - PASS
- Прокрутка между заметок - PASS
- Статус избранного переключается - PASS
- Содержание избранной заметки отображается на главном экране - PASS
- Заметка удаляется - PASS
- Снятие избранного у другой заметки не сбрасывает ранее выбранную избранную заметку - FAIL
    
## Интерактивное управление
- Основные элементы управления мышью работают - PASS
- Режим письма переключается - PASS
- Кнопка включения реагирует только при прямом наведении на неё - требует уточнения требований
