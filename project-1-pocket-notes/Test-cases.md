# ТС-001 - Создание заметки

## Предусловия

- Интерактивная модель загружена и отображается корректно 
- Устройство включено
- Список заметок пуст

## Шаги и ожидаемый результат:

1. Нажать средней клавишей мыши по "+"  
    **Ожидаемый результат:** открылся интерфейс заметки
2. Ввести заголовок  "Старая заметка"
    **Ожидаемый результат:** заголовок "Старая заметка" виден сверху слева
3. Нажать Enter  
    **Ожидаемый результат:** курсор отображается на второй строке
4. Ввести текст "Пример текста"  
    **Ожидаемый результат:** под заголовком отображается текст "Пример текста"
5. Нажать два раза на среднюю клавишу мыши  
    **Ожидаемый результат:** в списке заметок отображается созданная заметка с  заголовком "Старая заметка"


## Фактический результат

Заметка создана и отображается в списке заметок с заголовком и датой создания

## Статус 

PASS

# ТС-002 - Редактирование существующей заметки

## Предусловия

- Интерактивная модель загружена и отображается корректно 
- Устройство включено
- В списке существует заметка с заголовком "Старая заметка"

## Шаги и ожидаемый результат

1. Колёсиком мыши выбрать заметку "Старая заметка"  
   **Ожидаемый результат:** выбранная заметка выделена рамкой

2. Нажать среднюю кнопку мыши  
   **Ожидаемый результат:** открывается заметка, отображаются её заголовок и текст

3. Прокрутить колёсико мыши вверх до строки заголовка  
   **Ожидаемый результат:** курсор отображается в строке заголовка

4. Удалить текущий заголовок клавишей Backspace  
   **Ожидаемый результат:** строка заголовка пустая

5. Ввести заголовок "Название А"  
   **Ожидаемый результат:** в строке заголовка отображается "Название А" 

6. Дважды нажать среднюю кнопку мыши  
   **Ожидаемый результат:** отображается список заметок, изменённая заметка имеет заголовок "Название А" 

## Фактический результат

Заголовок заметки изменён на "Название А"  и отображается в списке заметок.

## Статус

PASS

# ТС-003 - Сделать заметку избранной

## Предусловия

- Интерактивная модель загружена и отображается корректно 
- Устройство включено
- В списке существует хотя бы одна заметка, имеющая заголовок и текст

## Шаги и ожидаемый результат

1. Колёсиком мыши выбрать заметку  
    **Ожидаемый результат:** выбранная заметка должна иметь черную рамку
2. Нажать среднюю кнопку мыши  
    **Ожидаемый результат:** откроется интерфейс редактирования заметки. Виден заголовок и содержимого текста, под заголовком
3. Нажать среднюю кнопку мыши  
    **Ожидаемый результат:** сверху справа, звездочка стала полностью черной
4. Нажать два раза на среднюю кнопку мыши  
    **Ожидаемый результат:** виден список заметок, справа отображается содержимое избранной заметки

## Фактический результат

Заметка стала избранной, её содержимое видно на экране списка заметок

## Статус

PASS

# ТС-006 - Переключение режима письма

## Предусловия

- Интерактивная модель загружена и отображается корректно 
- Устройство включено
- В списке существует хотя бы одна заметка, имеющая заголовок и текст

## Шаги и ожидаемый результат

1. Колёсиком мыши выбрать заметку  
    **Ожидаемый результат:** выбранная заметка должна иметь черную рамку
2. Открыть заметку нажатием средней клавиши мыши  
    **Ожидаемый результат:** откроется интерфейс редактирования заметки, виден заголовок и содержимое заметки
3. С зажатым Shift ввести с клавиатуры "текст", после ввода отпустить Shift
    **Ожидаемый результат:** На экране отобразится введенное большими буквами "ТЕКСТ"
4. Нажать один раз на клавишу Shift и ввести последовательность клавиш "ва дж бю йцукен"
    **Ожидаемый результат:** На экране отобразиться введенные символы "() [] ,. 12345"
5. Нажать один раз на Shift и ввести "текст"
    **Ожидаемый результат:** на экране отобразиться введенный текст "() [] ,. 12345текст"


## Фактический результат

Заглавные буквы и переключение режима письма работают корректно.
При вводе спец. символов одна из клавиш работает некорректно:  
    при нажатии клавиши "б" вводится "'", а ожидалось ","

## Статус

FAIL
