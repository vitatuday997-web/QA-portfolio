# BUG-004 - неверный символ при вводе в режиме специальных символов

## Окружение

- Браузер: Google Crhome
- ОС: Windows 11
- Версия приложения: текущая версия

## Предусловие

- Загрузилась интерактивная модель
-  Открыта заметка в режиме редактирования

## Шаги воспроизведения

1. Один раз нажать Shift для переключения в режим специальных символов
2. Нажать клавишу "Б"

## Ожидаемый результат

Вводится символ ","

## Фактический результат

Вводится символ "'"

## Воспроизводимость 

100%
