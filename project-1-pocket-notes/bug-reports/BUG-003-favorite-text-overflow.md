# BUG-001 - Текст избранной заметки выходит за границы области отображения

## Окружение

- Браузер: Google Chrome
- ОС: Windows 11
- Версия приложения: текущая версия

## Предусловие

- Загрузилась интерактивная модель

## Шаги воспроизведения

1. Нажать средней кнопкой мыши по "+", чтобы создать заметку
2. Ввести заголовок "Название 1"
3. Перейти к вводу содержимого заметки
4. Удерживать несколько буквенных клавиш 3–5 секунд, чтобы заполнить заметку большим объёмом текста
5. Нажать среднюю кнопку мыши, чтобы добавить заметку в избранное
6. Вернуться к списку заметок

## Ожидаемый результат

Текст избранной заметки остаётся внутри области отображения

## Фактический результат

При большом объёме текста содержимое избранной заметки выходит за границы области отображения и накладывается на другие элементы интерфейса

## Воспроизводимость 

100%
