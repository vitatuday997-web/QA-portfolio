# BUG-002 - Кнопка включения работает сквозь корпус

## Окружение

- Браузер: Google Chrome
- ОС: Windows 11
- Версия приложения: текущая версия

## Предусловие

- Загрузилась интерактивная модель

## Шаги воспроизведения

1. Прокрутить модель, чтобы кпнопку включения не было видно
2. Нажать ЛКМ, по месту где находится кнопка включения

## Ожидаемый результат

Устройство не включится

## Фактический результат

Устройство включается

## Воспроизводимость 

100%
